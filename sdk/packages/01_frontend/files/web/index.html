E6 connection / 机械臂连接

只发送固定状态查询；30004 被动读取一个反馈包并校验包头，不切换控制模式。

尚未检查。双网口直连需分别绑定本机网口；共用交换机时两台臂必须使用不同 IP。

接设备后，按这个顺序检查

  1. Quest 通过 USB 数据线接 PC，开启 Developer Mode，头显内允许 USB debugging。
  2. 点击“连接 USB Quest”；头显 Browser 打开 http://localhost:8765/quest，在头显内点击 Start AR。若不支持 AR，可选择 Start VR。
  3. 拿起左右手柄，分别前后、左右、上下移动，再转动手腕；核对左右卡片、位置和姿态是否一一对应。
  4. 依次按下并松开 Trigger、Grip、Thumbstick click、左 X/Y、右 A/B，并拨动两个摇杆。Meta / Menu 系统键通常不会由 WebXR 暴露。
  5. 退出 XR 或拔掉 Quest 数据线，卡片应变成失联/过期，数值停止显示为有效；重新接入后再保存短时记录。

有效数据状态仅表示收到新鲜跟踪数据；“人手动作与读数一致”仍需现场逐项核对。未连接设备时不产生示例数据。
