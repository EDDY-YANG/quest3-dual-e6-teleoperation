Checking WebXR support…

进入AR后，连接、机器人反馈、追踪、Grip和实际/目标末端位姿会直接显示在画面中。 两只手柄都可以用射线瞄准按钮、扣食指点击。单右臂可以全程用右手：右食指持续控制夹爪，右中指 Grip 控制跟随；右手 A 键也可点击按钮，按右摇杆可居中面板。

先点“连接 / 重检”，必要时回开始位。在“选择/标定”中选择参与侧，松开该侧Grip， 点“1 开始记录X”，沿该臂基座+X水平移动手柄至少80mm，再点“2 完成X标定 · 自动应用”。 双臂分别完成X标定，再用手柄指向正前方，点“一键记录操作者前方”。无需采集+Y。 当前默认从本次Grip起点1:1保持位置和旋转目标，平移方向固定；手停后仍可能继续追赶目标。 点击“开始遥操作”后按提示先松Grip再握持；松Grip暂停，重新握持取新起点。 STOP结束控制并收尾保存记录；网络恢复不会自动重新开始。

侧面的E6关节链、实测TCP和工具Z箭头是运动学参考视图，未与透视中的实物位置配准。 基座XYZ用于方向标定；工具Z箭头只显示末端朝向，显示长度不改变物理TCP。 无夹爪时仍存在Tool 0所定义的TCP和工具坐标轴。

Input reconnects after a network interruption without automatically re-arming the robot. Release Grip after reconnecting or putting the headset back on.
