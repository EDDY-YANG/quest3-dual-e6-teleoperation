Figure sources and interpretation

The setup and architecture illustrations are generated by tools/draw_figures.py as editable SVG and PNG. They describe the existing Quest/E6 application; no cloud service or hardware operation is required to render them.

The supplied assets/e6_model.png is reused when rebuilding the diagrams. Rendering that robot image from meshes requires the separately maintained SDK visual-model directory (model.json, meshes and UPSTREAM-LICENSE), selected with E6_MODEL_DIR. The full SDK/model conversion input is not bundled in this showcase.

  • E6 geometry: the official Dobot-Arm/DOBOT_6Axis_ROS2_V4 visual meshes, upstream commit 7807ef8fb31e8f86a76cd474a4a9cddffef6eca9, already retained in the SDK. The drawing uses an illustrative configuration, not measured feedback. Original license: assets/E6_MODEL_LICENSE.
  • Headset, controllers, PC and E-stop drawings: schematic symbols. They are not manufacturing geometry or electrical wiring instructions.
  • Power lines represent AC-mains / OEM-supply relationships. They deliberately omit unverified voltages, terminals and stop-circuit topology. Hardware E-stops are shown independent of PC/Wi-Fi; the drawing does not certify a safety architecture.
  • Robot links are physically separate because the existing source-bound setup uses matching controller IP addresses. No shared robot switch is implied.
  • The data-flow figure follows server.py, quest_lan.py, direction_calibration.py, relative_pose.py, left_z_trial.py, teleop_group.py, dobot_safe_sdk.py, e6_feedback.py and teleop_recording.py in the existing SDK.
  • Performance graphics are generated by tools/build_page.py exclusively from analysis/results_v4/summary.json. Blue = local IK without QP; orange = local IK with QP; purple = verified RangedIK v7 direct. They are historical descriptive results, not an advantage claim for the offline DLS hybrid.

This directory is a publication overlay, not a replacement SDK runtime. Keep the original SDK separately. No private raw event logs are bundled. A fresh machine needs the original logs to recompute the statistics and the official mesh assets to regenerate the robot rendering; the supplied SVG/PNG figures can be viewed directly.
