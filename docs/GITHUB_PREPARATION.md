# 仓库与 SDK 发行范围

[下载 Windows x64 SDK](https://github.com/EDDY-YANG/quest3-dual-e6-teleoperation/releases/latest/download/quest-e6-sdk-windows-x64.zip) · [v0.2.0 发行说明与校验值](https://github.com/EDDY-YANG/quest3-dual-e6-teleoperation/releases/tag/v0.2.0)

项目仓库包含网页、视频、图示和历史统计。Release 的具名 ZIP 包含可编辑的 13 个分包、预编译 DLL、依赖清单、VS Code 工作区及相关许可。可编辑 SDK 位于源码仓库的 sdk/。安装与验证请看[首次配置](SDK_INSTALL.md)，随后按 [01–06 示例](SDK_EXAMPLES.md)运行。

机器人地址、网卡绑定、回位数据、原始录制、证书和配对信息由使用者在自己的电脑上创建。离线研究代码接受用户提供的输入。历史统计仍按[原文口径](../analysis/methods.md)解读。
