本仓库发布项目展示网页、五段演示视频、系统图、真实日志统计摘要及分析/绘图工具。完整 SDK 的机器人控制源码、设备配置、Windows 原生库、原始运行日志和私有环境保留在单独工作包中，未随本展示仓库发布。操作手册和代码导读描述该单独 SDK，不代表 clone 本仓库即可控制机器人。

以下是未来公开完整 SDK 前需要完成的工作，不是访问本展示网页的安装步骤。

- README、代码导读、统一入口、各链路源码、测试、固定依赖与许可。
- 机器人／手柄可视化模型与第三方源码需要连同原 LICENSE、manifest 和来源归属保留。
- `packages/05_ranged_ik/files/runtime/rangedik_native/` 是交付所需原生库，不是普通会话日志目录。不要用一条全局 `runtime/` 忽略规则误删它而仍声称下载即可运行。

## 特别注意文件清单的一致性

各 `packages/<包>/package.json` 的 `files` 是组装输入清单。**只把历史数据加进 `.gitignore`，却仍在清单中要求它，会使别人 clone 后 assemble 失败。**

准备公开副本时，应一起完成：

1. 选择公开的源码／文档／数据范围，保留个人完整包。
2. 对配置提供真实可用的首次初始化流程；对不随仓库分发的研究数据明确来源、授权和安装位置。
3. 同步公开副本的文件清单、依赖、文档链接和验证条件，不以虚构数据填补缺失输入。
4. 从一个新的目录按 README 执行安装、组装与无设备检查，确认没有依赖原电脑的私有文件。
5. 查看实际待提交文件，确认没有私钥、采集日志或未经审阅的历史资料，再由用户发布。

根 `.gitignore` 故意没有静默排除仍被清单依赖的配置和研究数据，以免制造一个无法组装却看似可发布的仓库。它不是完整脱敏工具。

本 README 对当前行为的说明并不等于上述公开副本改造已经完成。若只上传 README 文本，保留与实际仓库结构一致的相对链接；若上传整个 SDK，先完成本清单。
